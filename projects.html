BloomCare E-commerce Platform

A pharmacy e-commerce platform built with TypeScript, Node.js, Express, and MongoDB. It provides REST APIs for authentication, medicine, cart, orders, reviews, pharmacy management, and administration.

How I built it

  1. Designed the database schema for users, medicines, and orders.
  2. Built REST APIs with Express and TypeScript.
  3. Integrated Stripe for payments and Cloudinary for images.
  4. Deployed the app on Render.

Technologies used

  • TypeScript
  • Node.js / Express
  • MongoDB
  • Stripe, Cloudinary, Render
